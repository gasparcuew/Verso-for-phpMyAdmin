Política de privacidad

Verso for phpMyAdmin · Última actualización: 14 de octubre de 2026

Esta política explica cómo Verso for phpMyAdmin gestiona la información, almacena las preferencias del usuario y utiliza los permisos del navegador.

1. Recopilación de datos

Verso for phpMyAdmin no recopila, transmite ni comparte con el desarrollador o servidores externos datos personales, historial de navegación, contenido de bases de datos ni otra información del usuario.

La extensión modifica la interfaz de phpMyAdmin para ofrecer opciones de personalización visual y herramientas de productividad. El acceso a una página compatible para proporcionar estas funciones no implica, por sí mismo, que su contenido sea recopilado o transmitido.

2. Almacenamiento de datos y preferencias

La extensión almacena preferencias de configuración, como el tema seleccionado, la densidad de la interfaz, las preferencias tipográficas, las etiquetas de servidores y otras opciones de personalización.

  • Almacenamiento local: las preferencias guardadas mediante chrome.storage.local permanecen en el dispositivo del usuario.
  • Sincronización opcional de Chrome: si esta función está implementada y el usuario la habilita, las preferencias compatibles pueden sincronizarse mediante chrome.storage.sync y el perfil de Chrome del usuario.

La extensión no utiliza estas preferencias para crear perfiles publicitarios ni rastrear al usuario entre diferentes sitios web.

3. Permisos del navegador

Verso for phpMyAdmin utiliza los permisos del navegador únicamente en la medida necesaria para proporcionar sus funcionalidades.

  • Storage: permite guardar los temas seleccionados, las preferencias de la interfaz, las etiquetas de servidores y otras configuraciones.
  • Scripting: permite aplicar las personalizaciones de la interfaz y las funciones compatibles en las páginas de phpMyAdmin.
  • ActiveTab: permite identificar o interactuar con la pestaña activa cuando el usuario utiliza las funciones correspondientes de la extensión.
  • Permisos opcionales de sitios: si la versión instalada admite esta funcionalidad, permiten utilizar la extensión en un sitio para el que el usuario haya habilitado expresamente el acceso.

Estos permisos no se utilizan para recopilar el historial de navegación ni para transmitir contenido de bases de datos al desarrollador.

4. Contenido de las bases de datos

Verso for phpMyAdmin está diseñada para mejorar la interfaz de phpMyAdmin. La extensión no recopila ni transmite intencionadamente al desarrollador o a servidores externos registros de bases de datos, contenido de consultas SQL, credenciales de acceso u otra información de las bases de datos.

Los usuarios deben seguir aplicando las prácticas de seguridad de su organización al utilizar herramientas de administración de bases de datos.

5. Servicios de terceros

La extensión no utiliza servicios de terceros para analítica, publicidad, rastreo o telemetría.

Si el usuario habilita la sincronización de Chrome, la infraestructura de sincronización del navegador puede procesar las preferencias compatibles de acuerdo con las políticas aplicables de Google.

6. Compartición y venta de datos

El desarrollador no vende datos de los usuarios ni los comparte con terceros para publicidad, elaboración de perfiles o fines ajenos a las funcionalidades de la extensión.

La extensión no está diseñada para transferir información personal a servidores externos.

7. Código abierto y seguridad

El código fuente está disponible para su consulta pública en el repositorio del proyecto en GitHub.

Los usuarios pueden revisar el código fuente para comprender el funcionamiento de la extensión y cómo gestiona las preferencias y los permisos del navegador.

La disponibilidad pública del código fuente no garantiza, por sí sola, que todas las versiones distribuidas sean idénticas al código publicado en el repositorio.

8. Cambios en esta política

Esta política de privacidad puede actualizarse cuando cambien las funcionalidades de la extensión, sus permisos o los requisitos aplicables.

La fecha de la última actualización se mostrará al principio de esta página.

9. Contacto

Si tienes preguntas sobre esta política de privacidad o sobre el tratamiento de información por parte de la extensión, puedes contactar con el desarrollador abriendo una incidencia en el repositorio del proyecto.
